Proxima is a next-generation real-time strategy game built entirely from scratch to bring back deep tactical gameplay, exceptional performance, and absolute player freedom.

Massive Unit Counts

Proxima will support 800 supply max by standard, allowing massive and intense firefights across the battlefield.

High Performance

Proxima has been built on the Godot 4 engine using revolutionary new techniques for path-finding AI, rendering, and dynamic environmental interaction.

Optimization

Proxima is exceptionally well optimized, supporting a wide range of legacy and modern hardware configurations seamlessly.

0 Purchased Assets

At Proxima Studios we soundly believe in maintaining our visual and stylistic integrity, so we build all assets completely in-house.

No AI Used

At Proxima Studios we believe that developing "in-house" means we will not, and cannot, use Artificial Intelligence (AI) tools for development.

Immersive Storyline

The Proxima universe features a unique and never-before-seen narrative focusing heavily on Politics, Resource Scarcity, and Disease.

Godot 4 Framework

Proxima has been custom-built from the ground up on the revolutionary Godot 4 framework, with nearly all game systems written in C#. Proxima leverages several complementary technologies, including JSON for maps, XML for unit charts, PNGs for UI elements, and Blender for 3D models.

Dynamic JSON Maps

Proxima stores map data cleanly as JSON files that define properties and statuses directly for tiles, avoiding bulky and complex pre-compiled map formats.

Groundbreaking Network Security

Proxima uses a combination of active and passive security measures to prevent bad actors from compromising matches or clients, including hash-based game verification, third-party server handshaking, and continuous sync verification.

Control Flexibility

Proxima features a seamless, familiar navigation system supporting WASD + QE, arrow keys, smooth scroll zooming, and edge-scrolling, letting you move and angle the camera anywhere across the battlefield with ease.

Real-Time Map Rendering

The minimap renders content in real time based on active units and terrain, enabling innovative features such as:

1. On-the-fly terrain modifications
2. Significantly faster load times
3. Player-created map features and terrain structures
4. Permanent or semi-permanent texture changes (e.g., craters, dunes)

API Support

Proxima includes a dedicated modding API at release, allowing developers to easily build and test custom mods directly in-game. Documentation is available upon request for personal use.*

*Documents provided are for personal or small team modding use only. Monetizing parts of the game, engine, or modding system is strictly prohibited.

Internet, What Internet?

Proxima stands out as a modern offline-first game that requires no internet connection to launch. This means absolutely zero telemetry, no data collection, and no user profiling.*
