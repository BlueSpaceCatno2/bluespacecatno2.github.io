The Rebirth Of RTS

Massive unit counts

Proxima will support 800 supply max by standard, allowing massive and intense firefights.

High Performance

Proxima has been built on the Godot 4 engine using revolutionary new techniques for path-finding AI, rendering, and dynamic environmental interaction.

Optimization

Proxima is well optimized, supporing most legacy and modern hardware.

0 Purchased Assets

At Proxima Studios we soundly believe in maintaining our visual and stylistic integrity, so we will be making all assets in-house.

No AI used

At Proxima Studios we also believe that developing "in-house" means we will not, and can not use Aritificial intelligence (AI) for development.

Immersive Storyline

The Proxima universe features a unique and never-before-seen universe focusing on Politics, Resource Scarcity, and Disease.

Next Generation Features

Godot 4

Proxima has been custom built from the ground up off of the revolutionary Godot 4 framework. Proxima has had (almost) its entirety of its systems written in C#. Proxima uses several other technologies for its systems including (but not limited to): JSON for maps, XML for unit charts, PNG's for UI elements, .blend and blender for 3D models.

F*cking Small Maps

Proxima stores map data as a JSON file that stores properties and status for tiles, instead of far more complex and bulky pre-compiled maps.

Groundbreaking Network Security

Proxima will use a combination of active and passive security measures to prevent bad actors for comprimising a game or client including hash-based game verification, 3rd party server handshaking, and constant sync verification.

Professional Control

Control Flexibility

Proxima uses a seamless, and familiar Navigation system, featuring WASD+QE, arrow key, scroll zoom, and side scrolling. It supports moving and angling the camera to anywhere on the battlefield.

Real-Time Map Rendering

The minimap (present in the lower left or upper right) renders its content real time based on units and terrain, allowing never before seen features such as:

1: On-The-Fly terrain changes

2: Faster load times

3: Player-Created map caustics & terrain.

4: Tempor-Permanent texture changes (e.g craters, dunes)

API Support

Proxima (at release) will have a modding API, allowing developers to easily develop, and test mods in game. Developers can request documentation for personal use.*

*Documents provided are for personal or small team modding use only, monitizing parts of the game, engine, or modding system is forbade, we reserve the right to change the function of the game at any time hindering mod functionality.

Our Missions

Internet, What Internet?

Proxima will be, one of few modern releases to be an offline-first game. Requiring no internet to launch! This means no telemetry, no data collection, and no profiling.*¹ *².

Modern Strategy

Proxima will mix aspects of modern computing, performance, graphics, and features, with the style and gameplay of the RTS's we used to love.

Real Skill

Proxima has been balanced, and tested to have an extremely high skill ceiling, attainable by anyone devoted.
